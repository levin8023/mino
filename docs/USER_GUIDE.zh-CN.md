# Mino 使用指南

## 整理图标

首次打开 Mino 会显示设置窗口。点「整理图标」后窗口隐藏，Mino 进入持续的整理模式，自动收起暂停。按住键盘上的 `⌘` 键，用鼠标把想隐藏的菜单栏图标拖到竖向三点 `⋮` 分隔符左侧；常用图标留在右侧。三根高低竖条形状的主按钮（菜单栏不显示文字）一定放在分隔符右侧。

整理结束后右键 Mino，选择「完成整理并收起」。macOS 会记住可拖动图标的位置；不是所有系统图标都允许移动。

## 日常操作

| 操作 | 结果 |
| --- | --- |
| 左键 Mino | 展开或收起左侧区域 |
| `⌃ ⌥ M` | 同上，可在偏好设置中关闭 |
| 右键 Mino 或 ⋮ | 打开使用说明、整理、设置与退出菜单 |
| `⌥` + 左键 Mino | 打开设置 |
| 点击展开状态的分隔符 | 打开使用说明 |
| 重新打开 Mino.app | 显示设置窗口 |
| 退出 Mino | 移除分隔符，释放菜单栏空间 |

## 始终隐藏

在偏好设置启用「始终隐藏分区」，会增加一个锁形分隔符并进入整理模式。按住 `⌘` 从左到右排列：始终隐藏图标、锁形分隔符、普通隐藏图标、`⋮`、三竖条主按钮、常驻图标。右键选择完成整理。

日常左键或快捷键不会展开锁形分隔符左侧；需要访问时，右键选择「临时显示始终隐藏区」，再次选择可重新隐藏。启用自动收起时，临时显示也会在空闲后结束。

macOS 27 自带的 `>>` 可以显示系统收纳的图标，包括始终隐藏区和 Mino 主按钮。该分区不是安全隔离。若找不到 Mino，先展开 `>>`，按住 `⌘` 把三竖条主按钮拖向常驻侧；也可重新打开 Mino.app 进入设置。没有公开 API 可以保证主按钮永不被系统收纳。

## 自动收起

默认开启，等待 10 秒；可选择 3、5、10、15、30 或 60 秒。鼠标位于屏幕顶部 400 点区域内、鼠标按钮按下、Mino 设置或右键菜单打开、整理模式进行中时，计时持续重置。关闭设置并离开顶部区域后，完整等待时间重新开始。

非常长的第三方下拉菜单可能延伸出保护区域；Mino 不读取其内容，无法保证识别每个菜单的打开状态。可临时关闭自动收起。

## 故障恢复

- **按按钮没有隐藏**：在设置查看位置警告，按住 `⌘` 将分隔符移到 Mino 控制按钮左侧。位置异常时程序会主动保持展开。
- **Mino 按钮看不到**：尝试 `⌃ ⌥ M`；也可在访达重新打开 Mino.app 显示设置，或用活动监视器退出 Mino。不要结束其他应用进程。
- **刘海挡住展开的图标**：减少常驻图标或切换到应用菜单较少的应用。第一版不提供独立图标浮窗。
- **快捷键无效**：偏好设置会显示注册失败信息，关闭其他冲突工具或禁用此快捷键，点击按钮仍可使用。
- **登录时没有启动**：先将 Mino.app 放入 `/Applications`，重新打开后关闭再开启「登录时启动」，按 macOS 提示批准。
- **切换显示器或睡眠后展开了**：这是恢复策略，确认位置后可再次手动收起。
- **多个分隔符干扰**：暂时退出其他菜单栏管理工具再测试。

## 卸载

在 Mino 偏好设置关闭「登录时启动」，退出程序，再将应用移入废纸篓。可选：退出后执行 `defaults delete io.github.levin8023.Mino` 删除本项目偏好设置。

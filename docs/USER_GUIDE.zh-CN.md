# Mino 使用说明

[简体中文](USER_GUIDE.zh-CN.md) | [English](USER_GUIDE.en.md)

菜单栏里三根高低竖条就是 Mino。图标不显示文字；悬停和右键菜单会显示名称。右键提供说明、设置和退出，按住 ⌥ 点击也能进入设置。应用没有 Dock 图标，重新打开应用会显示窗口。

## 切换语言

任意设置页顶部和右键菜单中都有「语言 / Language」，可选简体中文、English 或跟随系统。立即生效，不用重启。选择保存在本机。

## macOS 27 及以上

此系统下只创建一个 Mino 图标，不创建圆点、锁形分隔符，也不撑宽菜单栏。折叠、始终隐藏、自动收起和折叠快捷键暂不可用；点击图标打开设置。

`>>` 是系统空间不足时显示的入口。Apple 的公开设置没有单独关闭它的选项，Mino 无法保证它消失或将自己固定在外面。

可从 Mino 的「打开系统菜单栏设置」进入系统设置 → 菜单栏，在「允许在菜单栏中」选择应用。取消允许会关闭该应用的入口，不是可展开的折叠。Mino 内逐图标选择常驻、折叠或始终隐藏尚未实现。

## macOS 13–26 实验模式

只有旧系统保留分隔符实现，实际兼容性仍需验证。点击「整理图标」，按住 ⌘ 将普通隐藏图标放在 ⋮ 左侧，三竖条主按钮和常用图标在右侧。右键选择「完成整理并收起」，之后点击主按钮或按 ⌃⌥M 切换。

启用始终隐藏后，将锁形分隔符放在 ⋮ 更左侧，始终隐藏图标放在锁形分隔符左侧。普通切换不会展开此区；使用专门的临时显示菜单访问。此功能不是隐私隔离。

位置异常时会暂停折叠。屏幕变化、睡眠唤醒会展开以恢复访问。设置窗口、整理模式、鼠标按下或屏幕顶部 400 点交互区域内会暂停自动收起。退出会释放 Mino 分隔符占用的空间。

具体限制和安装方法见 [README](../README.md)。

# Security policy

Only the latest published preview is maintained. This early project offers no response-time guarantee.

Do not post credentials, exploit details, or private screenshots in public issues. Use [GitHub private vulnerability reporting](https://github.com/levin8023/mino/security/advisories/new) if enabled. If it is unavailable, open a public issue requesting a private reporting channel without including sensitive details.

Include the affected version, reproduction, expected impact, and mitigations in the private report. No remote access, root helper, network service, or updater is part of Mino 0.2.0.

Release downloads currently use ad-hoc signing and are not Apple notarized. Verify their source/checksums or build locally. An artifact checksum detects accidental or unmatched file changes; it is not a publisher identity signature.
